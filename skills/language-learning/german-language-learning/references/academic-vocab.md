## Daily Life Verbs (Alltag)

### Verbs with articles

| Verb | Article | Meaning |
|------|---------|---------|
| **besuchen** | - | to visit |
| **einladen** | - | to invite |
| **abholen** | - | to pick up |
| **bringen** | - | to bring |
| **helfen** | - | to help |
| **helfen** | bei + Dativ | to help with |
| **aufräumen** | - | to clean up |
| **reden** | - | to talk |
| **schicken** | - | to send |
| **tauschen** | - | to exchange |

### Important phrase: Zur Schule bringen
- **zur Schule bringen** = to take to school
- **zur Arbeit bringen** = to take to work
- **zum Arzt bringen** = to take to the doctor

### Important phrase: Bei Hausaufgaben helfen
- **bei + Dativ** = at/during/with
- **bei den Hausaufgaben helfen** = to help with homework

### Abholen (to pick up)
- **jemanden abholen** = to pick someone up
- **etwas abholen** = to pick something up
- **Das Paket abholen** = to pick up the package
- **Den Patienten abholen** = to pick up the patient
